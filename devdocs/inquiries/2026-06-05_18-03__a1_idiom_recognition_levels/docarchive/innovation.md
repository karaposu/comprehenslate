### Cluster CC-I — Template-adaptation rationale

**Why "frequency-tier" → "idiom-frequency tier" (light prefix-rename):** Idioms DO have Zipfian frequency distributions (idiom dictionaries provide empirical frequency data; some idioms appear far more often than others in corpora). The frequency-tier concept applies directly; only a light prefix-rename is needed to scope it to idioms.

**Why "register-tier" → "idiom-register tier" (light prefix-rename):** Idioms span casual → colloquial → journalistic → literary → archaic → biblical registers, like vocabulary does. Same concept; light prefix-rename.

**Why "substitution-test" → "idiom-handling test" (genuine replacement):** For vocabulary, the runtime action is single-word LEXICAL SUBSTITUTION (`purchase → buy`). For idioms, the runtime action is multi-action HANDLING: PARAPHRASE (replace with literal meaning); FAMILIAR-EQUIVALENT (replace with target-language idiom of similar meaning); INLINE-GLOSS (keep + explain); FOOTNOTE (keep + footnote); plus secondary LITERAL-WITH-EXPLANATION and OMIT-IF-DECORATIVE. The action vocabulary is named explicitly per Newmark / Baker translation-of-idioms research.

**Why adaptation is LIGHTER than syntactic-processing-capacity's:** Syntax had to replace frequency-tier entirely because sentences don't follow Zipfian distributions. Register-tier also needed reframing because syntactic register has its own dynamics. For idioms, both frequency-tier AND register-tier apply directly (with light prefix-renaming). Only the substitution-test analogue needs genuine replacement. The principle: **adapt where needed; preserve where it fits.**

**5-test verdicts:** PASS.

**Disposition: ACTIONABLE.**
