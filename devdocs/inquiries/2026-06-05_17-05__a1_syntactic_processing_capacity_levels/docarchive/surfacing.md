### Frontier flags

Questions surfaced during traversal but unresolved at the surfacing layer:

1. **Template adaptation question.** The vocabulary-breadth template has 4 components (reader-profile + frequency-tier + register-tier + substitution-test). For syntax: frequency-tier doesn't directly apply (sentences don't have a Zipfian frequency the way words do). What replaces frequency-tier? Candidates: **sentence-length tier** (operational); **embedding-depth tier** (cognitive); **working-memory-load tier** (matches user's framing); **complexity-tier** (umbrella). Sensemaking should adjudicate. Likely a single concept (the structural-complexity dimension) with multiple sub-dimensions (length + depth + suspension) — analogous to how frequency-tier in vocabulary-breadth is one concept with band gradations.

2. **Register-tier mapping for syntax.** For vocabulary, register-tier (everyday / colloquial / academic / literary / archaic) maps to LEXICAL choices. For syntax, register correlates with complexity (academic register is hypotactic and dense; casual register is paratactic and simple) but is not identical. Should the syntax template have a separate "register-tier" component, or is register subsumed in the structural-complexity tier? Sensemaking should adjudicate.

3. **Restructuring-test logic — which actions are primary at which levels?** G1-G7 surfaced 7 restructuring actions. Per-level prescriptions: very_basic needs SPLIT + UNEMBED + LINEARIZE + ADD-CONNECTIVES + REDUCE-NOMINALIZATIONS aggressively; native needs none (keep all structures). Mid-levels need subsets. Sensemaking should map actions to levels.

4. **Center-embedding boundary.** L3 says humans handle 1 center-embedding but struggle with 2. This is a hard cognitive boundary — where does it sit on the 5-level scale? Most candidate locations: between advanced and native (only literary native readers tolerate 2 center-embeddings in Henry-James / Faulkner). Sensemaking should confirm.

5. **Suspension-load boundary.** B2 (user's example) requires holding 3 clauses in working memory before main verb. The user's framing locates THIS at advanced (the example sentence ends with "succeeds" as the main verb after 25+ words of suspension). Native readers tolerate even more suspension (Henry-James 50+ words). Sensemaking should set the suspension-load thresholds.

6. **Language-agnosticism stress test for syntax.** English Subject-Verb-Object (SVO) canonical order. Japanese is Subject-Object-Verb (SOV) and head-final — embeddings work differently. German has verb-final in subordinate clauses. Russian has flexible word order. The CONCEPT of syntactic-processing-capacity holds universally (every language has complexity gradients) but specific structural cues vary. Sensemaking must verify that the level CONCEPTS work for at least one non-English target language without requiring template restructuring.

7. **Genre-anchoring per level.** F7 (Genre-anchored logic) surfaced: very_basic ≈ children's signs / early-reader; daily ≈ practical guides; conversational ≈ newspapers; advanced ≈ academic articles / educated literary fiction; native ≈ literary-difficult prose (Henry James, Faulkner, KJV-Pauline). Should the level definitions include genre anchors? Likely yes (parallel to vocabulary-breadth's reader-profile demographics).

8. **Migration mapping.** Existing AUDIENCE_LEVEL has 3 values (native / late_learner / late_learner_simple). For SYNTAX, the mapping is likely the same shape as vocabulary-breadth's (late_learner_simple → daily; late_learner → conversational; native → native; with very_basic and advanced as new positions). Sensemaking should confirm or refine.

9. **A1 sub-field independence stress.** Vocabulary-breadth and syntactic-processing-capacity are formally orthogonal (a reader can know all the words but lose the thread on dense syntax; conversely, a reader can parse complex sentences with limited vocabulary if they understand the words). Are the 5 LEVELS for syntactic-processing-capacity empirically correlated with the 5 LEVELS for vocabulary-breadth, such that the same-labels propagation produces sensible defaults? Likely yes (a `daily` reader is unlikely to be daily-vocabulary AND advanced-syntax in the typical case) but edge cases exist (non-native ESL professor: advanced vocabulary, conversational syntax). Sensemaking should test.

10. **Sentence-length thresholds per language.** For English, very_basic ≤6 words/sentence; daily ~10-15; conversational ~15-25; advanced ~25-40; native unlimited. For agglutinative languages (Turkish, Japanese), word-count is different (Turkish words pack more morphology). The CONCEPT (sentence-length tier) is universal; the thresholds are per-language. This is downstream (next inquiry per Constraint C2/language-agnosticism); flag noted.
