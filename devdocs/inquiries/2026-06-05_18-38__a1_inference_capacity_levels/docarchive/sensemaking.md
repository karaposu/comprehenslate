## Phase 3 — Ambiguity Collapse

### Ambiguity 1 — Template adaptation heaviness

**Counter:** HEAVY parallel to syntactic-processing-capacity (restructure all 3 non-reader-profile components fundamentally) OR LIGHT parallel to idiom (only replace substitution-test).

**Why fails:** Three components do need substantive adaptation (frequency-tier doesn't apply to processes; register-tier needs reframing for inference-demand; substitution-test → gap-filling test). But the underlying "tier + handling" pattern parallels closely — inference-load is an umbrella tier with sub-measures (like structural-complexity); gap-filling is named runtime actions (like restructuring). The OPERATIONAL structure parallels syntax's. So MEDIUM heaviness: substantively adapted but pattern preserved.

**Confidence:** HIGH.

**Resolution:** MEDIUM heaviness — three components substantively adapted; underlying tier+handling pattern preserved.

### Ambiguity 2 — Inference-load tier composition (umbrella vs separate components)

**Counter:** Split into 4–6 separate components (compression-depth + ellipsis + anaphora + pragmatic + presupposition + bridging).

**Why fails:** The 6 sub-measures are HIGHLY CORRELATED (a reader who handles 5-step compression typically handles long-distance anaphora and complex bridging). They jointly characterize the same cognitive capacity (working-memory + abstraction). One umbrella tier with sub-measures matches the structural-complexity-tier model from syntactic-processing-capacity. Adding 4–6 separate components over-engineers and violates the ergonomic bound.

**Confidence:** HIGH.

**Resolution:** ONE umbrella inference-load tier with 6 sub-measures.

---

### Ambiguity 3 — Gap-filling test (6 actions vs fewer)

**Counter:** Simplify to 2–3 actions (EXPLICATE / KEEP-AS-IS / FOOTNOTE).

**Why fails:** The 6 actions address DIFFERENT inference dimensions (EXPLICATE = compression; BRIDGE-CONNECTIVES = discourse coherence; RESOLVE-ANAPHORA = reference; UNPACK-COMPRESSION = telescoped chains; ADD-BRIDGING-INFERENCES = implicit causal/temporal; KEEP-AS-IS = preserve). Each maps to a sub-measure of the inference-load tier. Collapsing loses operational distinctions the translator-AI needs.

**Confidence:** HIGH.

**Resolution:** 6 primary actions + 1 secondary (ADD-PRESUPPOSITION-CONTEXT).

### Ambiguity 4 — Inference-capacity vs syntactic-processing-capacity orthogonality

**Counter:** They're so closely related they should be ONE sub-field.

**Why fails:** Parsing dense nested syntax (working-memory load on STRUCTURE — does the reader hold 3 clauses in suspension?) is operationally distinct from filling implicit logical steps (working-memory load on INFERENCE — does the reader fill 3 missing causal-chain steps?). Independent axes.

**Confidence:** HIGH.

**Resolution:** ORTHOGONAL sub-fields. Cross-sub-field interaction noted; both can be high simultaneously in literary-extreme prose but they're independent dimensions.
